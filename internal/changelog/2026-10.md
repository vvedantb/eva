# Changelog — October 2026

## Terminal `claude` matches the agent's CLI; Sonnet 5.5 and Opus 5.5 priced - 2026-10-01

- Launches already install the registry-latest Claude Code / Codex CLI under `/tmp/claude-cli` / `/tmp/codex-cli`, but terminal shells still found the snapshot's older copy first. `createSandbox` now appends `AGENT_CLI_PATH_LINE` (`_sandbox/vercelEnvFile.ts`) to `.eva-env.sh`, putting both install dirs ahead on PATH. The dirs are now exported from `vercelEnvFile.ts` and reused by `launch.ts`. The install guard and `resolvePinnedCliBinary` still compare manifests, so a stale copy first on PATH is still replaced.
- `CLAUDE_PRICING_PER_MILLION` gains `claude-sonnet-5-5` ($2 / $0.20 / $2.50 / $10) and `claude-opus-5-5` ($4 / $0.20 / $5 / $20), read from the Anthropic pricing page on 2026-10-01. Before this, Opus 5.5 prefix-matched the `claude-opus-5` row and was priced at $5 / $25.

## Unify chat-source docs and artifacts - 2026-10-01

- Backend: `convex/_chatSource/helpers.ts` owns source validators, create-time binding, access check, summary resolution and `by_source_*` listing; `docs.ts` and `artifacts.ts` dropped their copies. `chatSourceFields` is spread into both table schemas.
- Web: `sandbox/chatSource.ts` + `ChatSourceBadge` replace `docs/_source.ts` and `artifacts/_source.ts`; `ChatSourceArg` is derived from the backend args.
- Sandbox panes share `useSourcePanelItem` (one `?panelItem=<id>` param, matched against the pane's own rows), `SessionSourceDetail`, and `SessionSourcePane` now renders "View all" itself (`viewAllHref`).
- `NewDocumentDialog` is shared by the Documents sidebar and the sandbox tab; `useCreateDoc` handles the error toast.

## Notes from the sandbox Documents tab - 2026-10-01

- Sessions, quick tasks and projects: the sandbox Documents tab has a "New" button that creates a doc linked to that chat (title dialog).
- Docs in that tab now open in an inline panel editor (`SourceDocumentEditor`: back button, editable title, live-synced TipTap body) instead of navigating away; the open doc is the `?panelDoc=<numId>` URL param and only opens when linked to the current chat.
- Sandbox Artifacts tab: rows (and the row menu's "Open") show the artifact inline (`SourceArtifactViewer`, `?panelArtifact=<id>`) with back and open-in-new-tab, instead of navigating to `/artifacts/$id`. `ArtifactContent` is shared with the full viewer; both panels share `SessionSourceDetailHeader`.
- Documents sidebar: linked docs show a source pill (chat icon + "Task #12"); hover shows the full chat title.
- Shared helpers: `useCreateDoc` / `useOpenDocInViewer` (sidebar + panel), `useDocSync` + `baseDocEditorExtensions` (viewer + panel editor); `DocSourceArg` now lives in `docs/_source.ts`.
