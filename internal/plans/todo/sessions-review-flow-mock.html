Review flow: private by default, one reviewer, "Waiting for you"

A session is private to its maker until they ask someone to review it. Statuses: To do In progress In review Done. "Waiting for you" is not a column: it is how a session shows to the one person it waits on (Inbox, a badge, a filter). Vedant (dev) asks Priya (business) to review.

Private→ @Priya, Request review →In review · Priya→ Request changes →In progress · changes requested→ Request review again →In review→ Approve →Approved→ PR merges →Done

Solo dev work skips review: Private → PR merges → Done (stays private).
