Project Tasks: filters and labels

Eva creates every task now, so the Tasks list grows fast. Labels say what a task is about (ui, checkout, copy); Eva adds them when she creates or groups a task, and you can change them. A filter menu narrows the list by Label, Repo, Phase or Added by. Same pattern as the Quick Tasks list ("Filtered by" chips).
