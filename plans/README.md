## Findings considered and rejected

- Banned types (`any`, `as`, `!`): lint already enforces them in first-party code; the only violations are in vendored `apps/web/src/lib/stageshow/`.
- Frontend bundle splitting: `autoCodeSplitting: true` is on; `@xterm/xterm` is a type-only import.
- Staged turn left after a failed queued start: `claimStagedTurn` drops slots whose turn already closed.
- Out-of-order PR webhooks: `nextState === previousState` returns early, so they are idempotent enough.
- `saveResult` clearing a newer turn's slot (LOW confidence): not confirmed that a successful turn can have a null `result`; investigate only if stuck turns are seen.
- Tests excluded from CI and no reduced-motion support: documented, deliberate decisions.
